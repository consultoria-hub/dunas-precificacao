# Dunas Health — Sistema de Precificação Odontológica

Sistema web de precificação para consultórios odontológicos, com cálculo de **ponto de equilíbrio**, **preço sugerido**, **margem desejada** e **desconto máximo**. Catálogo pré-cadastrado por especialidade (ortodontia, exodontia, endodontia, prótese, implantodontia, etc.).

## Como usar

1. Abra **Parâmetros da clínica** e informe custos fixos, cadeiras, horas/mês, impostos e margem desejada.
2. Em **Precificação**, escolha a especialidade e clique no procedimento para calcular.
3. Salve. Os valores persistem no navegador (`localStorage`).

## Stack

HTML + CSS + JavaScript puro, sem dependências.
